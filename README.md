# Pixel Art Generator

A simple Python tool to convert normal images into pixel art instantly.

## Features

* Convert images into pixel art
* Supports JPG, JPEG, PNG
* Custom pixel size
* Fast and simple

## Installation

Install requirements:

```bash
pip install -r requirements.txt
```

## Run Tool

```bash
python main.py
```

## Build EXE

```bash
pyinstaller --onefile --console --name Pixel_Art_Generator main.py
```

## How To Use

1. Enter image folder path

2. Select image using index

Example:

```text
[0] image1.jpg
[1] image2.png
```

3. Enter save folder path

4. Enter pixel size

Example:

```text
50
```

5. Tool generates pixel art automatically

## Notes

* Supports PNG, JPG, JPEG
* Larger pixel size = more pixelated image
* Internet is not required
